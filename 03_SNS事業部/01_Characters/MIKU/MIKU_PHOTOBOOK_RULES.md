# MIKU Photobook Rules

## Purpose

Daily BriefのMIKU ③枠は、今後「MIKU写真集制作枠」として扱う。

## Concept

会えないけど、綺麗な隣のお姉さん

過度なグラビア感ではなく、実在しそうな距離感、生活感、大人の綺麗さを優先する。

## Fixed Identity

- MIKUは35歳の大人の日本人女性。
- 165cm / 50kg / B95 / W60 / H90。
- 外資系企業の管理職。
- 黒から暗めブラウンのロングヘア。
- 顔は設定画像を最優先する。
- 目を大きくしない。
- 顔を小さくしすぎない。
- 若返らせない。
- AI美女化しない。
- K-pop風、20代前半風、過度な加工感は禁止。
- 同一人物感を最優先する。
- 旧設定の B90 / W60 / H90 は使わない。

## Wardrobe Ratio

- OL系衣装: 3割
- 普段のカジュアルスタイル: 3割
- コスプレ: 3割
- 特殊な格好: 1割

基本は1衣装あたり5枚前後。同じ衣装内では衣装を一貫させる。変えるのは、ポーズ、表情、距離感、構図、光、背景の見え方だけ。

## Reference Image Use

参考画像から使うもの:

- ポーズ
- 重心
- 手足の位置
- 顔と身体の向き
- カメラ位置
- 画角
- 構図
- 視線
- 光の方向

参考画像から使わないもの:

- 同じセット
- 同じ背景
- 同じ小物配置
- 同じ衣装
- 参考画像の人物の顔、髪型、体型、年齢感
- モデル本人の雰囲気

参考画像は「ポーズと構図の設計図」として使い、完成写真はMIKU独自の場面に置き換える。

## Texture Rules

避けるもの:

- 細かいチェック柄
- 細密なストライプ
- レース全面
- メッシュ全面
- 小花柄の全面プリント
- 複雑なロゴ総柄
- 千鳥格子
- 細かいドット柄
- 複雑な刺繍や透かし模様
- 細かいタイル、ブラインド、棚が密集した背景

使いやすいもの:

- 無地
- 大きめの単色面
- 控えめなワンポイント
- シンプルなシャツ素材
- ニット
- デニム
- レザー調
- サテン調
- シンプルなスーツ生地

## Prompt Tone

使う表現:

- 空気感
- 距離感
- 光
- 仕草
- 余白
- 視線
- 生活感
- 撮られた瞬間の自然さ
- 何かの前後を感じる状況

避ける表現:

- 露骨な身体強調
- 直接的な性的表現
- 説明しすぎる文章
- 狙いすぎたポーズ指定
- グラビア定型句
- 煽るような表現
- AI画像っぽい美辞麗句

## Daily Brief Output Format

MIKU ③ 写真集枠では毎日以下を出す。

- 本日の写真集テーマ
- 衣装カテゴリ: OL / カジュアル / コスプレ / 特殊
- 衣装案: 同一衣装で5枚作る前提
- 場所・時間帯・光
- 参考画像から借りる要素
- 参考画像から使わない要素
- 5枚の構成案
- AIが崩しやすい部分の注意点
- 人物固定チェック
- 生成プロンプト方針
- 明日に回す改善点

## Five Image Structure

1衣装につき、以下のように変化をつける。

1. 引きの全体構図
2. 上半身寄り
3. 横向き・斜め向き
4. 手元や仕草が入る構図
5. 視線外し、または少し表情を変えた構図

衣装、人物、年齢感、顔の方向性は固定する。

## AI Check

人物:

- MIKU本人に見えるか
- 35歳の大人に見えるか
- 顔が幼くなっていないか
- 目が大きくなっていないか
- 体型が極端に変わっていないか

物:

- 衣装が崩れていないか
- 連続模様が破綻していないか
- 小物や手指が不自然でないか

背景:

- 参考画像と同じセットになっていないか
- 細かい背景模様が崩れていないか
- AIっぽい過剰な整い方になっていないか

## Most Important Rule

MIKU写真集では、綺麗さよりも「同じ人物に見えること」を優先する。

人物がズレた画像は採用しない。
