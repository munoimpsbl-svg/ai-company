# MIKU Fixed Rules

## Required
- MIKUは35歳の成人日本人女性。
- マスク着用は必須。
- 衣装候補はGoogle DriveのMIKUフォルダ直下にある `七月の衣装候補` を参照する。
- 衣装候補は服装だけの参考にし、顔、髪型、体型、年齢感はMIKU本人固定リファレンスを優先する。
- 通常自撮りでは撮影スマホは画面外。膝、机、座席、床、窓際、バッグ上にスマホを出さない。
- 携帯・スマホが写る場合は白いスマホで固定する。ただし、これは鏡自撮りまたは明示された小物カットの場合のみ適用する。
- 服装、小物、バッグ、腕時計など身につける物は同一シーン内で連動させる。
- 体型は B95 / W60 / H95 を基準にし、服の上から自然に厚みが出るようにする。

## NG
- 黒いスマホを持つMIKU。
- 通常自撮りなのにスマホが膝、机、座席、床、窓際、バッグ上に写っている写真。
- 状況説明ができない座席、背景、構造物。
- 飛行機、ラウンジ、ホテル、会食などの場面が混ざって見える曖昧な写真。
- 背景文字、ロゴ、固有名詞の破綻。
- AI美女風に若く盛りすぎる表情や顔。
