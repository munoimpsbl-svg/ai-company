# RIO References

## Folder Roles
RIOの参照資料は、用途ごとに必ず分けて使う。
混ぜて使うと顔・体型・髪型・構図が引っ張られるため、生成前に参照目的を確認する。

## Identity Reference
- `RIO_base_reference_2026-07-12.jpg`

用途:
- RIO本人感
- 顔
- 髪型
- 年齢感
- 体型

最優先。画質資料・構図資料より必ず優先する。

## 画質資料
- `quality_texture_refs/`

用途:
- 肌感
- 質感
- スマホ写真らしさ
- 光のムラ
- 軽いノイズ
- ピントの甘さ
- AIっぽさを避けるための空気感

禁止:
- 顔を似せない
- 髪型を似せない
- 体型を似せない
- 服装を似せない
- 同じ場所や状況を再現しない

## 構図資料
- `composition_refs/`

用途:
- 構図
- 連続写真の流れ
- 表情差
- 自然な笑顔
- 飲食店や外出時の距離感
- テーブルや人物の入り方

禁止:
- 顔を似せない
- 髪型を似せない
- 体型を似せない
- 服装を似せない
- 同じ店、看板、料理、器、席、椅子を再現しない
- コピー構図にしない

## Prompt Order
生成時の優先順位:

1. Identity Reference
2. Daily Brief
3. Character fixed rules
4. 画質資料
5. 構図資料

構図資料や画質資料が本人感を壊す場合は、その資料を使わない。
