# RIO Composition References

## Purpose
このフォルダは、RIO生成時の構図・連続写真・表情変化・自然な笑顔・飲食店での座り位置を参考にするための資料置き場。

## Allowed Use
- 連続写真の流れを参考にする。
- 無表情から笑顔への表情差を参考にする。
- 飲食店でのテーブル、料理、人物、背景の距離感を参考にする。
- 友人が撮ったような自然な正面寄り構図を参考にする。
- 食事中の手元、器、テーブルの入り方を参考にする。

## Forbidden Use
- 同じ店、同じ看板、同じ窓外の景色を再現しない。
- 同じ料理、同じ器、同じ席、同じ椅子を再現しない。
- 背景の固有名詞、店舗名、看板、ロゴ、文字を再現しない。
- 服装、髪型、顔、体型をこの資料に引っ張られない。
- RIO本人の顔固定・体型固定・髪型固定には使わない。
- 画像をそのまま真似たコピー構図にしない。

## Priority Rule
顔・髪型・体型は必ず `../RIO_base_reference_2026-07-12.jpg` を最優先にする。
このフォルダの資料は、構図と写真の流れだけに限定して使う。

## Prompt Rule
生成プロンプトでは、このフォルダの資料を使う場合、必ず以下を明記する。

- composition only
- do not copy the exact location
- do not copy signs, logos, text, food, tableware, or background
- do not use this as identity reference
- identity must follow RIO base reference
