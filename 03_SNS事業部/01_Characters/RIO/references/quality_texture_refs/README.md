# RIO Quality References

## Purpose
このフォルダは、RIO生成時の画質・肌感・質感・スマホ写真らしさを参考にするための資料置き場。

## Allowed Use
- 肌の自然な質感を参考にする。
- スマホ写真らしい軽いノイズ、柔らかいピント、圧縮感を参考にする。
- 光のムラ、暗さ、自然な影、屋外や室内の空気感を参考にする。
- AIっぽいツヤ、過度な美肌、均一すぎる肌を避けるために使う。

## Forbidden Use
- 顔、目、鼻、口、輪郭を似せない。
- 髪型、髪色、前髪を似せない。
- 体型、服装、ポーズを似せない。
- 同じ場所、同じ状況、同じ背景を再現しない。
- 画質資料を本人固定資料として使わない。

## Priority Rule
顔・髪型・体型は必ず `../RIO_base_reference_2026-07-12.jpg` を最優先にする。
このフォルダの資料は、画質だけに限定して使う。

## Prompt Rule
生成プロンプトでは、このフォルダの資料を使う場合、必ず以下を明記する。

- quality and texture only
- do not use this as identity reference
- do not copy the exact location or situation
- identity must follow RIO base reference
